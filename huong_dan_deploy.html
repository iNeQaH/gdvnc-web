🚀 Hướng Dẫn Deploy GDVNC (Vercel + TiDB Serverless)

Đây là giải pháp dễ dàng và tối ưu nhất để đưa hệ thống GDVNC của bạn lên mạng hoàn toàn miễn phí. TiDB cung cấp database MySQL Serverless tương thích hoàn hảo với Prisma.

Bước 1: Tạo Database trên TiDB Serverless

1. Truy cập TiDB Cloud và đăng ký tài khoản (có thể đăng nhập bằng Google/GitHub).

2. Chọn tạo một cluster Serverless (miễn phí trọn đời).

3. Sau khi tạo xong, vào mục Overview > Chọn Connect.

4. Ở phần Connect, chọn loại kết nối là Prisma. TiDB sẽ cung cấp cho bạn một chuỗi kết nối DATABASE_URL.

Bước 2: Chuẩn bị mã nguồn

Đẩy toàn bộ mã nguồn GDVNC của bạn (folder hiện tại) lên một kho lưu trữ (Repository) trên GitHub.

Lưu ý: Không tải file .env lên GitHub để bảo mật thông tin.

Bước 3: Triển khai (Deploy) trên Vercel

1. Truy cập Vercel và đăng nhập bằng tài khoản GitHub.

2. Nhấn nút Add New Project.

3. Chọn Repository chứa mã nguồn GDVNC từ GitHub và nhấn Import.

4. Ở phần Environment Variables (Biến môi trường), thêm các cấu hình sau:

  • DATABASE_URL: [Dán chuỗi kết nối lấy từ TiDB ở Bước 1]
  • JWT_SECRET: [Copy từ file .env local của bạn]
  • CAPTCHA_SECRET: [Copy từ file .env local của bạn]
  • Các biến SMTP khác (SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, SMTP_FROM) nếu bạn cần tính năng gửi mail.

5. Bấm Deploy và đợi Vercel xử lý khoảng 1-2 phút.

Bước 4: Khởi tạo Schema Database

Vì TiDB là database mới, bạn cần khởi tạo các bảng (tables) cho nó.

Mở Terminal (Command Prompt) ở máy tính của bạn và chạy lệnh sau (lưu ý đổi DATABASE_URL thành link TiDB):

set DATABASE_URL=mysql://[user]:[password]@[host]:4000/[db_name]?sslaccept=strict
npx prisma db push
npx prisma db seed

(Hoặc bạn có thể thiết lập lệnh này chạy tự động trên Vercel trong thẻ Build Command, nhưng chạy local để cấu hình lần đầu là an toàn nhất).

🎉 Hoàn tất!

Sau khi Vercel deploy xong và Database đã có cấu trúc, bạn có thể truy cập bằng đường link (domain) Vercel cung cấp. Dự án GDVNC của bạn đã online!
